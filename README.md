# HUNTKEEPER: Idle Trails

### Small on your desktop. A journey of its own.

A compact desktop idle hunting game featuring a hunter, a dog, and a growing collection of adventures.

| Status | Built with | Repository purpose |
| :--- | :--- | :--- |
| In development · Playable prototype | Godot · Windows | Public project showcase |

## The experience

- Automatic hunts in a compact desktop window.
- A hunter and dog progressing through different regions.
- Equipment, crafting, and lodge upgrades that shape progression.

## Development status

This project is a work in progress. The description reflects the current direction and may change during development; it is not a release announcement.
